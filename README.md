# 中國用語檢查工具

檢查文案檔案（`.txt`、`.csv`、`.xlsx`）中的中國用語，提供台灣慣用語建議並產出 Excel 檢查報告。
詞庫外置於 `中國用語對照資料庫.csv`，更新詞庫只需覆蓋這個檔案。

提供兩種使用方式，共用同一份詞庫與同一套比對規則：

| 方式 | 適合對象 | 入口 |
|---|---|---|
| **網頁版**（GitHub Pages） | 所有同仁，免安裝 | 開啟網址即可 |
| **Mac 終端機版** | 想離線或批次處理 | 雙擊 `中國用語檢查.command` |

兩個版本都只在本機處理檔案，文案內容不會上傳到任何伺服器；網頁版的所有運算都在瀏覽器內完成。

---

## 網頁版：部署到 GitHub Pages

第一次部署（只做一次）：

1. 在 GitHub 建立一個 repository（公開 repo 才能免費使用 Pages）。
2. 把這個資料夾的內容上傳到 repo 的根目錄。網頁版只需要這四個檔案，其餘檔案一起放著也無妨：
   - `index.html`
   - `app.js`
   - `matcher.js`
   - `中國用語對照資料庫.csv`
3. 到 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 一兩分鐘後網址會出現在同一頁，格式為 `https://<帳號>.github.io/<repo 名稱>/`。把網址分享給同仁即可。

### 定期更新詞庫

1. 用 Excel 編輯 `中國用語對照資料庫.csv`，另存時選 **CSV UTF-8（逗號分隔）**。
2. 到 GitHub repo 頁面，點 **Add file → Upload files**，把新的 CSV 拖進去（檔名相同即會覆蓋），按 **Commit changes**。
3. 約一分鐘後網頁自動生效；網頁頂端會顯示目前載入的規則數與詞庫更新時間，可據此確認。

上傳前想先試跑：網頁的「試用自訂詞庫」可以載入你電腦上的 CSV 草稿，只在本次瀏覽有效，不影響正式版。

## Mac 終端機版

1. 把整個資料夾放到共用位置或複製給同仁。
2. 雙擊 `中國用語檢查.command`（第一次若被系統擋下，在檔案上按右鍵 →「打開」一次即可）。
   首次執行會自動建立 Python 環境並安裝 openpyxl（需要網路，約一分鐘）。
3. 把要檢查的檔案拖進終端機視窗後按 Enter，可一次拖多個。
4. 報告會存在 `檢查報告/` 資料夾，檔名為 `原檔名_檢查報告_日期時間.xlsx`，並詢問是否開啟。

指令模式：

```bash
python3 main.py 檔案1.xlsx 檔案2.txt [--含低風險] [--不開啟報告]
```

## 詞庫格式

UTF-8 with BOM 的 CSV，八個欄位：

| 欄位 | 說明 |
|---|---|
| 編號 | 流水號 |
| 中國用語 | 要偵測的詞；多個寫法以「／」分隔（例：賬號／賬戶） |
| 台灣慣用語 | 建議替換詞 |
| 類別 | 資訊科技、網路社群、飲食、服飾、食品製造、營養保健…… |
| 風險等級 | 高／中／低 |
| 備註 | 語境說明 |
| 例外詞 | 以「;」分隔。命中詞若落在任一例外詞內則跳過（例：生粉 的例外詞填 花生粉） |
| 啟用 | 是／否。「否」表示暫停此規則但保留紀錄 |

### 維運原則

- **風險等級語意**：高＝台灣讀者一眼可辨，公開文案一律替換；中＝已部分滲透，正式文案仍建議替換；低＝已通用或語境可接受，僅供參考（不影響通過判定）。
- **誤判處理**：在該詞的「例外詞」欄補上正確詞（如「花生粉」），不要刪除規則。
- **單字或太籠統的詞**（如「牛」「檸檬」）無法靠例外詞窮舉，請「啟用」改「否」並在備註寫明原因。
- **公司決定不管的詞**：「啟用」改「否」，保留紀錄。
- 建議每季檢視低風險詞的滲透狀況並更新。

比對規則：最長詞優先（「沒過食材」命中後不再重複回報「沒過」）、套用例外詞、只比對「啟用＝是」的規則、預設檢查「高＋中」。

## 開發與測試

```bash
python3 -m unittest discover -p 'test_*.py'
```

```bash
node test_matcher.js
```

Python 版（`matcher.py`、`readers.py`、`checker.py`、`report.py`、`main.py`）與 JavaScript 版（`matcher.js`、`app.js`）的比對引擎行為一致，兩邊的測試都涵蓋規格書列出的最低案例。
